# 路线图

[English](../../docs/maintenance/roadmap.md) | [架构](../design/architecture_cn.md)

运行时是**目标设计，尚未实现。** 下面各项是可执行清单。勾选一项需要该阶段写明的验证，而不是只改文档。

## 阶段 A — 只读驱动

- [ ] 固定 `can_left` 和 `can_right`。
- [x] 实现 `CanTransport`。
- [x] 用 `record_can` 记录原始 CAN 帧。
- [ ] 识别固件档位。
- [ ] 解析两条臂的关节反馈。
- [ ] 把每个解析字段与 `pyAgxArm` 对比。

验收：连续运行 30 分钟，无断连，无未解释报文，解析状态与官方 SDK 一致。

## 阶段 B — 单臂安全运动

- [ ] 实现使能和失能。
- [ ] 实现位置命令。
- [ ] 实现软件限位。
- [ ] 实现看门狗。
- [ ] 实现急停。
- [ ] 在一条真机上做小幅度低速运动。

验收：断开客户端、停止心跳或拔掉 CAN 后，系统进入文档中的安全状态。

## 阶段 C — 双臂服务

- [ ] 每条总线使用自己的接收线程。
- [ ] 同步两条臂的状态。
- [ ] 原子提交双臂动作。
- [ ] 应用基本工作空间盒子。
- [ ] 提供 [IPC 契约](../interfaces/ipc_cn.md)。

验收：一条臂的样本过期时，两条臂都停止推进。

## 阶段 D — 示教采集

- [ ] 在 C++ 进程中读取两台示教器。
- [ ] 采集相机。
- [ ] 对齐时间戳。
- [ ] 实现 LeRobot `Robot` 适配。
- [ ] 实现 LeRobot `Teleoperator` 适配。
- [ ] 录制、回放并检查 10 条数据。

验收：回放时两条臂、两只夹爪和图像事件的顺序一致，没有明显时间错位。

## 阶段 E — 策略部署

- [ ] 训练 ACT 基线。
- [ ] 缓冲动作块。
- [ ] 闭环滚动预测。
- [ ] 统计真机成功率。
- [ ] 接入 SmolVLA。
- [ ] 以后接入 OpenVLA-OFT。

## 第一版明确不做

MIT 力矩模式保持关闭。未经验证的高速 CPV 保持关闭。固件不匹配不会被绕过。多个客户端不能同时控制机械臂。模型不发送原始 CAN 帧。软件按钮不是急停。硬件阶段通过之前，项目不宣称实时等级或安全等级。

cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
ctest --test-dir build --output-on-failure
